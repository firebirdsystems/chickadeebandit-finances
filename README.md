# Finances

A [Chickadee Bandit](https://chickadeebandit.com/app-library/finances) app.

Household budget tracker — create spending budgets, log transactions, and see how much remains each period.

## Features

- Spending budgets per category and period.
- Log transactions against a budget.
- See how much remains each period.
- Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-finances/releases/latest/download/bundle.json
```
